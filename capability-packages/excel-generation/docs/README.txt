Excel 生成 / org.workbench.excel

边界：只把调用参数写成 XLSX，不产生业务内容，不设定估算比例、表头、配色、报价或目标值。没有网络请求、模型调用或任意脚本执行入口。调用规则放在独立技能 excel-generation-guidelines；业务规范由 workload-estimator 等业务技能提供。

构建：使用工作台 runtime-node/node.exe 运行 build.mjs，并将现有 runtime-dev/node_modules 目录作为唯一参数。脚本将已安装的 @wekanteam/exceljs 及其实际依赖打入独立 CommonJS 文件，汇总许可证，再生成 dist/excel-generation.zip。构建只读取依赖，不联网安装，不要求运行用户另装 Office、Python 或 openpyxl。

导入：通过功能中心的现有 ZIP 导入机制。将本能力关联到岗位，再按业务需要绑定 Excel 生成规范和对应业务技能。仅导入不会自动修改其他岗位。

输出：通过现有能力任务机制保存结果，由宿主认证下载接口返回 XLSX，不接受用户文件路径，不覆盖已有业务文件。普通文本（即便以等号开头）仍按文本写入；只有显式公式对象/公式规则会写入公式。

支持：最多20工作表、单表10000行/256列/20000单元格，输入受宿主256KiB限制，生成XLSX最多350KB。支持普通值、内部公式、矩形格式、合并、列宽行高、冻结首行和筛选。公式原样保留并设置打开重算；没有内置公式计算器。公式对象可带调用方已算好的result缓存，但生成器不证明该缓存正确。

不支持：宏、外部数据连接/外部公式、任意代码、既有二进制模板导入、原文件就地编辑、图表。需要既有模板样式时，由技能将已知结构/公式/样式描述为生成参数。该版本不得声称完整复用未读取的模板。
