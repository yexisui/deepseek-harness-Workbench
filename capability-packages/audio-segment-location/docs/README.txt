录音分段定位 1.0.0

此包采用 dsh-worker-v1 模板，策略入口为 execute。
输入：duration（总秒数）、silences（start/end 秒数组）。
输出：timingKind=chunk、连续不重叠的 start/end 秒区间。
目标约22秒；优先使用15～30秒范围内停顿，没有停顿时按25秒分段。
最后一个片段可以短于15秒。时间只表示音频片段边界。

工作台需提供音频处理连接：本包不读取录音、不接收密钥，不自行调用模型。
添加到会议岗位后，工作台负责本地停顿检测、切片、现有转写接口调用及来源回听。
移除后新任务走原来的整段转写。历史内容保留。
独立动作可输入 JSON 验证分段策略，不等于实际录音链路已接通。
