流程图生成能力

在能力中心导入并启用后，在岗位编辑中添加“流程图生成”并保存，使用该岗位新建对话。
示例：把前面的总结做成标准流程图；把十二个步骤做成蛇形流程图；把第三步改为资料审核。
模型复用工作台默认设置。固定模板使用系统中文字体，无额外画图程序、网络字体或外部CDN。
当前支持2–60个节点，蛇形为每行3步；含分支或返回的流程使用标准图。支持局部文字、节点、连线修改；复杂或不明确的修改会要求确认，原图保留。
在回复中查看预览，点击查看大图可下载PNG，SVG可直接下载。历史图保留，修改生成新图；用户无需管理版本。
需要包含能力图像结果与会话关联支持的工作台。仅把此包导入较旧宿主不能提供完整图像预览与连续修改。
许可：Apache-2.0，与工作台一致。无第三方绘图库。SVG/PNG均为确定性模板渲染，模型只整理流程数据。
