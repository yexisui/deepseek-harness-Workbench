# @linxin666/dsh-client-ui-plain-chat

[English](README.md) | 中文

为本地 DSH 工作台提供无需选择工作区的普通聊天，由网页版和 Electron 界面共用。

## 能力

- 空白会话页可以直接输入文本，无需选择工作区。首次发送创建使用 `workbench-chat` 预设的会话；同时发送的操作共用一次创建请求。
- 初始输入框支持文本。创建会话后，后续消息使用原有会话输入框和模型控件。首次请求使用已配置的默认模型。
- 选择工作区通过既有工作区流程打开独立项目会话，该流程可能复用该项目的空白会话。首页未发送的草稿仅在项目输入框没有草稿时转交；聊天历史不会移入该项目。
- 顶层“新会话”进入空白普通聊天草稿；工作区内的新会话保持原有行为。未分组历史的标题显示为“聊天”，已有未分组会话也在这个标题下显示。

## 安装

这是独立于已发布聚合包和创意工坊登记的本地私有插件。它需要官方 DSH `0.1.5-rc.1` 客户端组件以及仓库共享构建配置。先构建插件，再通过 web profile 的依赖与 bundle 登记挂载本地包；仅修改源码或安装 Electron 不会激活它。

按工作台安装流程直接使用 pnpm 链接包，并在 profile 中登记 bundle。当前 DSH 的 plugin-link 转发不能可靠处理本工作台包含空格的路径。开发依赖保留在外置开发运行环境中。bundle 登记变化需要用户自行重启 DSH；不要自动中断正在运行的服务。

## 配置

宿主根据 `DSH_HOME` 推导存储位置，在该目录旁创建 `chat-data`，并将其路径提供给浏览器。本工作台对应 `dsh-data` 及其同级的 `chat-data`。会话持久化和模型凭据仍由既有 DSH 服务管理。

插件将自带预设安装到 `DSH_HOME/.agent-presets/workbench-chat`；该目录由插件管理，其文件会在宿主插件加载时刷新。需要调整预设时修改包内源码，而不是已安装副本。插件不会替换项目的默认预设或模型配置。

插件没有独立设置项。发送消息需要配置默认模型并连接宿主。缺少启动元数据时，初始发送被禁用并显示重启提示；创建失败时保留草稿供重试。

## 安全模型

专用预设使用完整的通用助手提示词，关闭运行时上下文注入。其能力边界以空白名单隐藏继承工具，并通过作用域内的守卫拒绝工具执行，包括随后注册到同一作用域的工具。预设不挂载项目文件、终端、网络搜索或委派工具。

`chat-data` 为普通会话提供独立工作目录，本身不是操作系统沙箱。限制针对本预设中模型的工具执行，不涵盖所有宿主功能或所有第三方插件。模型请求仍使用既有提供商配置及其数据处理规则。插件不保存 API Key 或访问令牌。

## 已知限制

- 当前 rc.1 集成使用可撤销的组件登记装饰器，适配已有的 `ConversationRoot`、`SidebarRoot` 和 `WorkspaceBrowser` 条目，同时保留原注入回调、已声明子树和状态存储。公开 shadow 机制无法复用这些已声明子树，因此 SDK 变化时需要复核这层兼容桥。
- 空白页输入框仅支持文本。会话创建后，附件及其他高级输入行为由原输入框提供，受模型能力与普通聊天工具限制约束。需要模型调用文件读取工具的文件无法在普通聊天中读取。
- 选择工作区会创建或打开独立项目会话，不会转换已有聊天、切换其预设或转移其消息历史。已有项目会话及其模型、连接阻断保持原有行为。
- 最小预设没有上下文压缩，长对话可能达到模型上下文上限。草稿使用浏览器会话存储，属于尽力保存。
- 已通过 17 项定向测试。在隔离的真实 Web 界面中，已确认无需选择工作区即可发送消息、创建普通聊天会话，并保留原模型控件。未验证真实模型回复；现有 Electron 窗口需重启后加载插件。
