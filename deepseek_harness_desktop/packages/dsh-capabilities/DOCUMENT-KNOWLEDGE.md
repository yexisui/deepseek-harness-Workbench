# 智能文档使用外部知识库

更新：2026-10-26。外部知识库已作为功能中心独立模块；在文档岗位中平级关联“智能文档”和“外部知识库”，选择允许范围并保存。新文档对话启用外部资料时，经统一权限网关检索。仅使用当前文档时不要求接入知识库。

文档原文以P编号引用，外部资料以K编号引用；当前未保存的编辑快照继续作为文档上下文。外部引用保存来源快照与检索记录，知识库更新不改写历史回答。修改仍生成待审候选，不直接覆盖原文档。

可在独立模块配置兼容的HTTP服务，或由宿主插件实现 `knowledgeProvider`，详见[独立模块接入契约](KNOWLEDGE-PROVIDER.md)。现有 `documentKnowledge` 仅作旧协议兼容，继续支持没有资料集概念的旧文档适配器；新提供方优先。文档旧状态接口 `/api/capabilities/documents/knowledge` 保留，管理入口统一进入独立模块。

凭据只由服务端适配器管理，不放入岗位配置、会话响应或日志。独立模块已补齐连接表单，可测试、保存、取消和移除；本机提供可运行的文本向量检索示例。未配置时仍显示待接入；连接检测不代表问答质量已验收。没有新增运行依赖或下载Embedding模型。
