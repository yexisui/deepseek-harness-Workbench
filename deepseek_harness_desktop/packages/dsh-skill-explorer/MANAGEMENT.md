# Skills 导入与管理

入口：设置 → Skills 技能。插件管理服务提供同一套管理界面和接口；原技能侧栏开启时复用这套组件。

- 支持单个 SKILL.md、技能文件夹和 ZIP；多个技能可逐项选择。
- 元信息需要 YAML `name` 和 `description`。名称使用小写英文、数字和连字符，最多 64 字符。拒绝重复 YAML 键、路径越界、符号链接和超过 500 文件 / 32 MiB 的包。
- 文件夹中的脚本、模板和引用资源一起复制。原文件保持不变；不会自动安装依赖、运行脚本或把 Codex 专用工具转换为工作台工具。
- 全局副本位于 DSH_HOME/skills；项目副本位于当前会话项目的 .dsh/skills。管理记录和保留版本位于 DSH_HOME/skill-management。
- 同名更新保留上一版本；另存副本需要新名称；相同版本跳过。不会覆盖未纳管目录或用户在外部修改的文件。
- 总开关控制自动和手动调用；自动选用开关另外遵守原技能的调用策略。已放入对话上下文的说明无法撤回，已有任务不强制中断。
- 导出包含原始版本的完整文件；回退或回收站恢复后保持停用。移除只清除运行副本，版本资产保留。
- 页面显示的是配置状态。工具连接、脚本环境和实际任务成功需要独立验证。

插件列表与能力中心共用 InventoryTree 和 EnableSwitch。全局开关按精确条目 ID 写入配置，支持热更新时应用，否则显示待重启；内置预设、岗位生成预设及基础管理服务显示不可切换原因。本地普通预设修改只影响后续新会话。

本模块不把导入的技能注册为可发布能力，也不改变岗位授权和执行路由。技能中的第三方工具名称及本机绝对路径可能需要手工适配。未纳管的旧技能仍保留旧自动选用开关和原管理入口。

实现使用已有导入安全校验、ZIP 读写、技能加载器和管理接口信任边界。导入预览有过期时间，写入检查状态版本，避免过期页面覆盖新状态。版本文件和管理记录分别原子落盘；发生系统崩溃时保留的版本可用于人工恢复，不宣称跨文件事务具备数据库级崩溃恢复。
