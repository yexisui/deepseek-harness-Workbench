## 问题：外置能力包构建产物缺失

`/api/capabilities/state` 返回的 3 个能力包：

| 能力 | ID 前缀 | 状态 |
| --- | --- | --- |
| 录音分段定位 | local-603c79b3 | installed=true，loaded=false，ready=false |
| DSH 计算器 | local-80a17072 | 同上 |
| 流程图生成 | local-24a8fe74 | 同上 |

报错一致：

```
构建产物未就绪：ENOENT: no such file or directory, scandir
'<WORKBENCH_ROOT>\dsh-data\capabilities\packages\releases\<哈希>'
```

说明：能力定义仍在 state.json 中，但运行所需的发布文件目录不存在。依赖这些能力的岗位（如流程图演示助手、会议录音分段定位）在执行时预计会失败；该影响为推断，未在界面中实际执行。

### 已核实事实

- dsh-data/capabilities/packages 下 releases、uploads、exports 均为空目录，修改时间 2026-10-11 14:57。
- dsh-data/capabilities/state.json 与 shared-settings/files/capabilities/state.json 内容完全一致。
- scripts/settings-sync.cjs 共享 capabilities/state.json，但不包含 packages/releases 下的发布文件。
- offline/capability-packages 中有 audio-segment-location-latest.zip、flowchart-generation.zip、BrowserSkill-0.3.0-offline.zip；没有 DSH 计算器的包。

### 待核实的可能原因

以下为推测，尚未验证：设置共享或离线部署把能力记录导入了本机，但没有同时导入或重建对应的发布文件，导致记录与文件不一致。

### 影响范围

- 只涉及上述 3 个外置导入的能力包：能力记录已随共享设置同步，发布文件没有，表现为“已安装但不可用”。
- 会议纪要、需求分析等内置能力接口正常返回、配置显示就绪；未实际执行，不代表已验证可用。

## 接手说明（供其他电脑的协作者）

- dsh-data 是本机运行数据，不进 Git；以上 releases 为空的现象来自本机（作者电脑）。接手前先在自己电脑查看能力中心状态或 `GET /api/capabilities/state` 中 packages 的 loaded/ready/message，确认是否同样缺失。
- 共享设置只同步 state.json，不同步 packages/releases；修复时不能只改 state.json，需让发布文件随之存在。
- offline/capability-packages 里可用的包：audio-segment-location-latest.zip（录音分段定位）、flowchart-generation.zip（流程图生成）；源码在 capability-packages/。DSH 计算器无现成包，需用户确认是否保留。
- 修复后按 AGENTS.MD 第 9.5 节验证：岗位引用保留、能力加载为 ready，并在客户端实际执行一次；结果更新本文件和台账 T036。
