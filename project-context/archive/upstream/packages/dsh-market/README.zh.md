# @linxin666/dsh-client-ui-market

[English](README.md) | 中文

定制 DSH 工作台的本地创意工坊：在设置面板导入和管理自己的皮肤、宠物、插件与 Agent 预设。

## 能力

- 保留工坊入口与四类选项卡，显示本地数量、搜索和资源状态。
- 支持 ZIP 资源包与选择文件夹；确认前显示名称、类型、版本、大小及替换冲突。
- 独立复制资源文件，无需保留原文件夹；复用现有设置卡片、控件和主题变量。
- 展示已有资源，但不接管其删除权限。此卡片不请求线上目录、预览图片、排名，也不发送工坊心跳；不包含在线下载器、在线安装路由和验证框架。

## 安装

使用定制工作台的部署或重新构建入口。脚本将五个受影响包构建到 runtime-dev，并通过 profile 的 workspace overrides 选择本地包。运行中的宿主可能需要用户重启。同版本的公开 npm 包属于上游发行版，不包含本次定制。

## 配置

dsh-web-ui-market 开关关闭后隐藏资源库，仅保留开关。导入和资源操作即时执行；卡片的「保存」只保存启用开关。

| 分类 | 资源包要求 | 导入后 |
| --- | --- | --- |
| 皮肤 | 有效的 v2 skin.json、样式表及引用文件 | 在「设置 → 皮肤」应用；可执行 hooks 另行授权 |
| 宠物 | 有效的 pet.json 与精灵图、帧动画或 Live2D 资产 | 重启工作台后，在「设置 → 宠物」选择 |
| 插件 | 声明 dsh.bundle.patch 的 package.json、补丁文件及已构建 JavaScript 入口 | 确认安装，等待成功，按提示重启 |
| 预设 | preset.yml 和 agent.cordis.yml | 确认启用，再通过原有预设控件选择 |

每次导入一个资源。ZIP 可以外包一层文件夹。预设未显式声明 ID 时，优先采用符合要求的外层文件夹名，否则根据名称生成稳定 ID。

## 已知限制

- 资源 API 仅供本机回环客户端使用。插件依赖安装可能需要联网。
- 限制：2,000 个文件，单文件或 ZIP 最大 200 MiB，展开后每个资源最大 500 MiB。拒绝加密、ZIP64 和带符号链接的压缩包。
- 替换前需停用正在使用的资源；已安装插件需要卸载，正在安装时需等待任务结束。同 ID 替换需要确认。
- 导入资源和备份属于私人运行数据，被 Git 忽略。Git 恢复源码，不恢复这些文件。

## 安全模型

导入只检查文件，不求值脚本、不加载插件、不启用预设。路由检查回环地址、Host 和 Origin；提交前校验路径、清单、必要入口、ZIP 完整性及数量大小限制。

每次导入生成 dsh-workbench.import.json，记录文件摘要和归属。执行授权另行保存并绑定本次导入的准确内容；包内来源记录不能授予信任。皮肤 CSS 继续经过皮肤中心的安全处理。

插件安装和预设启用复用现有管理器及其冲突、名册和默认项检查。插件任务使用不可变的安装副本，报告真实执行结果。

## 存储与恢复

资源保存在 DSH_HOME 下：skins/、pets/、agent-presets/（未启用）、.agent-presets/（已启用）和 workshop/plugins/。暂存、授权、安装快照与备份位于 workshop/。

替换和移除时，旧目录保留在 workshop/backups。最终移动失败会恢复旧目录。恢复时先停用当前资源，再选择对应备份文件夹重新导入。
