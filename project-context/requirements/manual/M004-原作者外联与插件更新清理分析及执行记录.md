## 分析与决定

### 遥测

原共享客户端遥测会创建浏览器访问标识，并向原市场站点发送插件名称、版本和资源信息。处理共享源、同步清单、生成副本及实际调用，避免下次同步或构建恢复上报。本地 Doctor 健康心跳和远程设备存活心跳用于本机/局域网通信，继续保留。

### 作者插件更新

原侧栏更新属于作者插件全家桶更新，目标是作者 npm 范围及原 GitHub 发布说明，与官方 Harness 基座升级分开。移除该入口、后台检查和执行实现。插件管理中取消更新检查及更新动作，旧接口应明确拒绝，不执行查询或更新。安装与卸载流程按用户追加要求继续保留。

Doctor 另有针对旧作者聚合包的自动迁移。已移除启动时触发与联网安装，历史 `autoMigrate=true` 不再生效；手动 `migrate` 命令只读检查旧配置，发现旧包时提示手动部署并返回退出码 2。官方基座安装、救援与诊断流程不变。这里依据源码清理的是更新、遥测及公网连接能力，没有据此认定原项目存在恶意后门。

### 工坊及公网连接

保留已有本地 ZIP、文件夹导入和资源管理；清除不再使用的旧市场下载与验证组件。公网 Cloudflare 隧道、原市场 relay 注册及其设置入口移除，保留 LAN 地址、配对、撤销和访问校验。历史配置中的公网开关不能再次启动已移除功能。

皮肤修复只从本地镜像恢复，缺少镜像时保留现有文件并提示重新导入本地 ZIP 或文件夹，不再回退下载原市场资源。历史来源字段继续用于识别已安装资源，不产生请求。桌面打包脚本取消专供公网隧道的 cloudflared 下载和存在性断言，Node、npm、pnpm 与 Electron 下载流程保留。

### 保留功能

供应商余额/额度查询、Doctor 既有本地诊断与安装修复、Node/Electron/包管理器部署下载、官方 Harness 更新和模型接口均保留。它们在无外网的环境中是否可用，仍取决于网络、软件源和模型配置，不将本次改动描述为完全离线部署。

## 实施方式

1. 记录工作台当前未提交的创意工坊改造，复制到独立工作副本并保存文件 SHA-256 基线。
2. 在副本中修改并验证，保留已有本地改造；不通过 Git reset 或覆盖整棵源码恢复。
3. 仅将与基线不同的文件同步回指定源码目录；同步前核对真实项目是否发生并发变化，并备份本次触及的原文件。
4. 重新构建受影响的独立包和聚合客户端，更新正式 profile 选择的本地构建，防止源码已更新但实际仍加载公开 npm 原版。
5. 不停止、不重启运行中的 DSH 服务。需要用户重启后才能确认新宿主及客户端的实际加载。
