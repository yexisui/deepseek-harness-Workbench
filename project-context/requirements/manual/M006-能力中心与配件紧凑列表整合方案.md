结合红框位置，此处“选项卡”理解为浏览器操作、文档处理等配件卡片；“长度”理解为卡片横向宽度；参考对象是中间已添加能力的紧凑行，而非右侧设置面板的页签。

## 2. 命名、入口与职责

| 位置 | 名称与职责 |
| --- | --- |
| 设置一级入口 | **能力中心**：与 Agent 预设/岗位助手相邻，集中管理可供助手使用的能力 |
| 中心中的管理对象 | **能力组件**：按业务用途命名，例如“浏览器操作”；BrowserSkill 作为来源或技术名称 |
| 创建岗位助手的左侧 | **能力配件库**：能力中心的选用入口，可搜索、筛选、拖入或添加 |
| 岗位助手 | 组合能力，并编辑当前岗位的使用要求及允许覆盖的设置 |
| 插件 | 继续管理插件安装、启停、版本、依赖等底层事项，保留现有分类 |
| 创意工坊 | 继续承担本地资源收集与导入，使用现有安装流程 |

能力中心和配件库使用同一份能力身份与元数据。一个能力可关联一个或多个底层插件；不将全部底层插件自动展示为能力。新增入口不是再安装一份 BrowserSkill，也不是复制一套能力记录。

## 3. 能力中心的管理方案

首页提供搜索，以及“常用、全部能力、待配置、未被使用”等筛选。支持置顶常用能力，让浏览器操作有稳定入口；在配件库标题附近提供“管理能力”入口。

中心卡片显示：业务名称、来源、简短说明、配置/连接状态、引用岗位数量，以及“配置能力”“查看使用岗位”。能力状态与岗位引用情况分别呈现，避免把“已添加”误当作“已连接”。

能力详情建议分为：

1. 概览与连接：说明用途、可用范围和连接状态，未来接入实际连接操作。
2. 使用说明：编辑能力说明、操作规则及示例，承担用户所说的独立编辑与处理。
3. 默认配置：例如浏览器选择、可访问站点、操作范围和提交确认。
4. 使用岗位：列出引用该能力的岗位，并提供跳转入口。

包名、版本和底层依赖放在折叠的“技术信息”内。能力中心提供全局默认值，岗位助手保留岗位专属设置；未来实现继承时应明确标记“使用默认值/此岗位覆盖”，修改默认值前展示受影响的岗位范围。

以上连接、引用数量、保存和继承属于后续功能设计。首轮若仍只做 UI，应明确标识示例与未连接状态，不将静态样例当作实际运行信息。

## 4. 左侧配件库改为紧凑列表

### 信息结构

每个配件改为一条紧凑卡片：左侧图标，中间两行文字，右侧添加或已添加标记及拖拽把手。

- 第一行：浏览器操作。
- 第二行：BrowserSkill，用弱化文字显示来源。
- 右侧：未添加显示“＋”，已添加显示“✓”；焦点或悬停可查看动作含义。
- 拖拽把手保留，整张卡片主体仍可拖入。

移出左侧卡片的内容：完整用途介绍、独立“示例”徽标、大面积底部操作区，以及重复的文字提示。现有顶部预览提示统一说明示例性质，具体用途在选中后的右侧详情中查看；悬停或键盘聚焦可以补充简短提示，但关键信息不能只靠悬停获取。

左侧“已添加”表示配件已放入当前岗位，不表示 BrowserSkill 已连接或实际能力已启用。选中态与已添加态使用不同视觉标记，避免混淆。

### 宽度和高度

卡片宽度填满左栏的可用内容区，扣除统一内边距和滚动条空间；随侧栏拖动实时伸缩，不采用固定卡片宽度。图标、操作按钮和拖拽把手保持稳定尺寸，文字区弹性伸缩。

建议样式起点：32 像素图标、约 64–72 像素行高、约 8 像素卡片间距。具体数值在实施时结合主题和可点击区域调整，不将这些建议值视为固定需求。

名称与来源各保留一行；过长时省略，详情和焦点提示提供完整内容。窄栏优先保留名称和操作，避免强制换行让列表重新变高。宽栏也沿用紧凑结构，不自动展开整段介绍。

列表填充侧栏剩余高度，内容超出时纵向滚动；每张卡片不随侧栏高度拉伸。搜索和分类保持易于访问，可在列表滚动时固定在上方。收起侧栏时仍显示现有窄边条，不把卡片压缩成不可用的极窄状态。

### 交互

- 点击卡片主体：选中并打开右侧详情；此操作不自动添加。
- 点击“＋”或拖入中间：添加能力，沿用当前轻微落位回弹及短暂高亮；不强制展开已收起的右栏。
- 重复添加：定位并高亮中间已有卡片，不重复生成。
- 已添加的左侧条目仍留在原位，维持列表顺序与查找习惯。
- 移除操作保留在中间已添加卡片，左侧“✓”不兼作移除按钮。
- 点击操作按钮与拖拽手势分别处理，避免添加、查看和拖动互相误触；保留键盘可操作性和减少动态效果支持。

中间已添加能力与左侧列表统一图标、名称和来源的视觉层级，中间额外保留岗位状态和移除入口。

## 5. 与现有方案的完整使用路径

能力中心配置和维护能力 → 创建岗位助手 → 从左侧紧凑配件库选用 → 拖入中间组合 → 在右侧调整当前岗位设置 → 需要修改能力本身时前往能力中心。

从岗位编辑器前往能力中心时，优先采用覆盖式详情或可返回的内部导航，保留当前未保存的岗位表单；不能因打开管理入口丢失编辑内容。能力组件身份稳定，中心详情、左侧列表和中间卡片指向同一个能力。

现有中间主栏始终保留，左右栏仍可独立隐藏、拖动缩放、点击或拖动窄边条恢复；隐藏后保留当前编辑内容，窄屏继续使用侧边抽屉。

### 已实现

- 设置列表注册独立“能力中心”页面，顺序紧邻 Agent 预设；保留原插件、外观与岗位预设入口。
- 能力中心与岗位配件库共用能力目录、图标和配置字段。首页支持搜索、常用置顶、全部/常用/待配置/未使用筛选；详情提供概览与连接、可编辑使用说明、默认配置、使用岗位和折叠技术信息。
