## 已确认需求

能力在能力中心管理，可添加到岗位助手；关联并保存后，新岗位对话可根据前文总结生成用户指定的标准或蛇形流程图。用户无需学习提示词、代码或画布编辑器。内置提示词提取结构，固定模板确定字体、形状、颜色、排版和连线。通过对话修改文字、步骤和关系，或切换模板；不能为套用蛇形模板删掉业务分支。失败保留原图，历史对话能继续修改。预览及图片下载保持简单。

## 实现

- 能力源：`capability-packages/flowchart-generation`；标准 `dsh-worker-v1` 包，名称“流程图生成”，动作“生成与修改流程图”。沿用能力中心、组件目录、岗位一次保存、授权、启停、导出及移除机制，没有新增专属管理页。
- `resources/create.txt` 和 `edit.txt` 是固定提示词；模型复用已有工作台默认模型。局部修改返回操作列表，不由模型重写整张图。
- `runtime/main.cjs` 确定性 SVG 渲染；标准图支持判断、条件、分支、汇合与返回；蛇形每行3个步骤、连续折返，2–60节点。中文使用系统中文字体；长文字自动换行及扩展高度。无第三方画图库、网络字体或新增外部工具。
- 宿主 PackageRunner 记录会话ID，并向能力提供同一能力、同一岗位、同一会话的上一份结果。显式目标图必须属于当前会话，失败任务不会成为最新成功图。
- 工具返回结构和图像链接，避免把SVG字节放入模型上下文；结果按原有任务记录持久化。每次修改产生独立图像地址，历史图保持不变，用户不用管理版本。
- 图像、下载和查看页复用能力接口的认证与来源检查。SVG响应禁止脚本/外部资源；查看页提供适应宽度、原始大小、PNG/SVG下载。
- 工作台没有新增模型配置；正式演示使用新建的“流程图演示助手”，仅关联本能力，既有岗位绑定保持。
