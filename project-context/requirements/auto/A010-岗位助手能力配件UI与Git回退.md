## 界面与边界

岗位配置窗口采用能力库、助手配置、配件设置三栏。能力库包含浏览器操作、文档、表格、知识库、本地文件和邮件六种示例配件，支持搜索、分类筛选、拖拽或按钮添加、移除和启停，拒绝重复添加和未知拖放项。右栏提供 BrowserSkill 的浏览器选择、网站范围、操作权限和提交确认选项，以及其他示例配件的目录或资料来源字段。

岗位名称、职责、原配色和要求/输出格式保留；右栏可以切换配置预览，展示岗位内容和能力组合。宽屏为三栏，中屏下移设置栏，窄屏上下排列。保留原预设列表、当前助手入口和普通聊天流程。

所有新增数据均为 React 组件内存状态。关闭配置窗口后丢弃，不写 localStorage/sessionStorage，不安装插件，不读取安装目录，不调用浏览器、不保存真实预设、不改变工具权限或模型调用。保存并启用仍禁用，连接状态标注未连接。示例岗位的初始能力组合也只是预览。
