## 运行方案与已有分析

项目包含 DSH Web 插件、Electron 桌面壳和创意工坊，Agent 运行依赖官方 DSH 宿主。

此前提供的安装方案将 @deepseek-ai/dsh@0.1.5-rc.1 和 pnpm@11.24.0 安装到 runtime，将 DSH_HOME 指向 dsh-data，通过 web profile 安装 @linxin666/dsh-web-all@0.3.23。版本组合来自本地源码的宿主基线与插件版本；本记录不声称已完整安装成功。

已有源码分析中发现：
- 桌面 runtime 的 profile 清单仍固定 dsh-web-all@0.3.19，不会自动包含本地 0.3.23 源码修改。
- scripts/link-profile.mjs 不读取 DSH_HOME，直接使用默认用户 .dsh 路径；后续源码挂载前需处理该隔离缺口。

这些是此前静态检查的结论；后续修改或升级后应重新核对。
