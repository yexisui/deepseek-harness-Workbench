## 日常启动

在工作台根目录双击 [启动桌面端.cmd](../../../启动桌面端.cmd)。

该入口调用同目录的 [start-desktop.ps1](../../../start-desktop.ps1)，检查必要文件，指定现有 Node、DSH 和数据路径，再打开 Electron 桌面窗口。无需重新安装、编译插件或制作 exe 安装包。PowerShell 的执行策略参数仅作用于此次启动进程，不修改系统的长期策略。

关闭桌面窗口会按原有生命周期停止它自己启动的后台宿主；不要在桌面任务执行过程中关闭窗口。原有网页版宿主由其自己的启动入口管理。

## 目录职责

| 路径 | 当前用途 |
| --- | --- |
| runtime-desktop | 用户已安装的 Electron 44.1.1 |
| runtime | 已有 DSH 0.1.5-rc.1 与 pnpm 11.24.0 |
| dsh-data | 已有模型设置、插件和会话 |
| desktop-state/user-data | Electron 用户数据 |
| desktop-state/session-data | 浏览器会话缓存 |
| desktop-state/logs | 桌面日志 |
| dsh-web-0.3.23/desktop | 直接运行的桌面源码 |

Node 使用系统安装，不额外复制进源码。桌面独立选择 3082–3181 范围内的空闲端口，不占用网页版保留端口 3080/3081。

## 实际改动

- desktop/src/runtime.cjs：增加显式的外部开发运行路径解析，校验绝对路径，并要求已有 web profile。
- desktop/src/main.cjs：接入外部开发运行时，设置独立状态目录，在开发模式跳过 profile 播种；打包模式仍使用原有内置载荷。
- desktop/tests/runtime.test.mjs：补充开发模式隔离、路径校验和已有 profile 保留测试。
- desktop/README 中英文配对文档：说明外部开发环境。
- 源码内新增配对 Agent Note，记录方案与取舍。
- 根目录新增上述两个启动文件。

源文件修改前的备份保存在当前协作工作区的 desktop-dev-integration/original 中。该备份只用于本次改动对照，不属于桌面运行依赖。源码目录不是 Git 检出，因此未提交或推送。

## 开发启动验证中的修正

本机 PATH 包含多个 Node 可执行文件。Windows PowerShell 查询返回多条路径时，直接赋给环境变量会拼成无效路径。启动入口已明确选择 PATH 中的第一个 Node 可执行文件，重试成功。此为实施记录，不需要用户执行额外纠错命令。
