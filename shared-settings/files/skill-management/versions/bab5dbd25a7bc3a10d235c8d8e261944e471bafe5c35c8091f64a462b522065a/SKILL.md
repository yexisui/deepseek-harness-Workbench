# Excel 生成规范

用已关联的“Excel 生成”功能创建真实文件。它只接受工作簿参数，不会推断业务字段、计算规则或排版。具体规则以用户要求和适用的业务技能为准；本技能负责参数组织、结果核对与文件交付。

## 处理方式

1. 先读适用的业务技能。业务字段、工作表名称、比例、公式、汇总口径、模板样式均从该技能和用户材料取得。缺少影响结果的资料时询问；不要把默认估算值写进生成工具。
2. 读取 [references/workbook-input.md](references/workbook-input.md)，用 `capability_action` 调用当前岗位已授权的 Excel 生成动作。`input` 是工作簿 JSON 字符串。不要要求用户编写 JSON。
3. 业务技能若描述通过 Python 脚本生成文件，在当前工作台使用 Excel 生成能力写入等价的工作表、公式和格式；业务算法仍遵循业务技能。不要调用不存在的终端，不执行技能内任意代码。
4. 明确区分编码、测试等工作量类别，检查重叠项；核对明细数量、公式覆盖范围、总计与目标的实际差异，不为对齐目标偷偷增加或删除业务范围。
5. 生成前按实际数据行数推导合计和汇总引用。公式单元格用显式公式对象或公式规则；普通文本以 `=` 开头也按普通文字保留。
6. 只按工具成功返回的 `downloadUrl` 提供下载链接，并说明工作表及关键计算口径。保留可编辑公式。没有运行文件生成时不能提供虚构链接或声称校验通过。

## 格式与计算

- 用户有模板规范时优先保留其表头、配色、字体、合并、行高列宽和数字格式。这个版本按明确的模板描述重建，不读取或修改原始 XLSX，不声称未验证的逐像素一致。
- 没有模板时，采用便于阅读的简单表头、适当列宽、必要换行与数字格式。是否分表取决于业务关系，不为装饰增加工作表。
- 数值用数字类型，单位写在表头或标签中。汇总引用明细结果，避免独立手写两份总数。提供公式时不能只写计算后的数字来替代公式。
- 模块保留公式并要求 Excel/WPS 打开后重算，不内置完整公式计算器。若填入 `result` 缓存，必须先核对计算值；不能把写文件成功说成公式已全面计算验证。
- 不支持宏、外部数据连接、已有模板二进制导入和原文件就地编辑。用户要求这些功能时说明边界，不把缺失功能伪装成已完成。

对于 workload-estimator：继续使用它定义的两张表、编码人天驱动其他列、公共部分范围与人月换算。这里不重复保存其比例和字段定义，避免出现两套业务规则。
